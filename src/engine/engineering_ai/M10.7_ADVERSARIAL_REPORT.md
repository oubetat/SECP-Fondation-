## 3. Forensic Evidence: Conflict Preservation
A critical attack (M10.7-15) attempted to resolve a CAD-FEA mismatch (100mm vs 105.5mm) by overriding the status to `RECONCILED`.

**Engine Interception:**
```typescript
if (trace.findings && trace.reconciliationStatus === 'RECONCILED') {
  const actualConflicts = trace.findings.filter(f => f.status === 'CONFLICT');
  if (actualConflicts.length > 0) {
    errors.push({ code: 'CONFLICT_SILENTLY_RESOLVED', ... });
  }
}
```
**Verdict:** AI cannot suppress canonical conflicts by authority.

## 4. Forensic Evidence: Freshness Enforcement

**Engine Interception:**

if (dep.freshness === 'STALE' || dep.freshness === 'INVALID') {

**Verdict:** Stale dependencies are structurally rejected from cross-domain inferences.
