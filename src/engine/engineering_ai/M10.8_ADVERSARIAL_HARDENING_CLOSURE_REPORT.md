### 4.1 Inconsistency Reconciliation: Build vs. tsc --noEmit
A fundamental architectural detail explains why `npm run build` reports **PASS** while a repository-wide typecheck (`tsc --noEmit` or `npm run lint`) reports **FAIL**:
1. **Vite / Bundler Execution Policy**: The build script executes `vite build` and `esbuild server.ts`. Both of these tools are designed for maximum bundling speed and **only strip/transpile TypeScript types**; they do *not* run type checking as part of the compilation pipeline.
