# SECP — M10.10: Model Identity & Context Binding Acceptance

This document certifies that all model, execution, context, and claim identities are deterministic and fully protected against tampering.

---

## 1. Deterministic Identity Formula
Every reasoning trace, evidence envelope, or context binding generates an ID incorporating all key canonical inputs using SHA-256:
- `modelId`
- `modelVersion`
- `contextHash`
- `executionHash`
- `claimId`
- `evidenceId`
- `deterministicSeed` (where applicable)

Any attempt to modify these fields after identity generation causes an immediate **identity drift mismatch** or **checksum error**, prompting immediate rejection.

## 3. Forensic Trace Evidence
In `EngineeringReasoningEngine.ts`:
```typescript
const recomputedId = this.computeReasoningId(
  parsed.modelId,
  parsed.contextHash,
  parsed.executionHash,
  parsed.evidenceId,
  parsed.claimId,
  parsed.conclusion,
  parsed.inputs || {},
  parsed.canonicalRevisionHash || '',
  parsed.revisionId || ''
);

if (recomputedId !== parsed.reasoningId) {
  throw new Error(`REASONING_REHYDRATION_ERROR: Reasoning ID tampered: expected ${parsed.reasoningId}, computed ${recomputedId}`);
}
```
